# Saylani Advanced Python – 15 Tasks

This repository contains my solutions to 15 practical Python programming tasks completed as part of the Saylani Advanced Python course.

## Topics Covered

- Python Fundamentals
- Data Structures
- Functions and Recursion
- Object-Oriented Programming (OOP)
- File Handling (JSON and CSV)
- Exception Handling
- Decorators and Generators
- Unit Testing

## Technologies

- Python 3
- JSON
- CSV
- Unittest

## How to Run

Run any task using:

```bash
python task_01.py
```

Replace `task_01.py` with the task number you want to run.
